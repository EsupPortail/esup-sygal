# Version 10.3.0

## 1. Sur le serveur d'application

- Placez-vous dans le répertoire de l'application puis lancez la commande suivante
  pour installer la nouvelle version :

  ```bash
  git fetch --tags && git checkout --force 10.3.0 && bash ./install.sh
  ```

- Suivez la doc suivante pour configurer la mise en cache du tableau des rôles par privilège afin d'accélerer l'init 
  du moteur d'ACL et (donc le temps de chargement de toutes les pages de l'application) : 
  https://git.unicaen.fr/lib/unicaen/privilege/-/blob/master/readme.md#cache


## 2. Dans la base de données

- Exécutez dans l'ordre les scripts SQL présents dans le répertoire correspondant à la présente version.


## 3. Sur le serveur d'application

- Lancez la commande suivante pour vider le cache des attributions de privilèges aux rôles :

  ```bash
  $ vendor/bin/laminas privilege:clear-cache --key 'privileges_roles'
  ```

NB : Pas grave si le message "[ERROR] Aucune donnée dans le cache pour la clé 'privileges_roles' !" apparaît.
